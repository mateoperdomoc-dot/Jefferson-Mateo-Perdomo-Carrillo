Sesión 2 - CSS

¿Qué es CSS?

CSS significa Cascading Style Sheets. Permite darle color, tamaño, posición y diseño a una página web.

Selectores

  • Selector de etiqueta
  • Selector de clase
  • Selector de ID
  • Selectores combinados

Propiedades CSS

Algunas propiedades importantes son:

  • color
  • background-color
  • font-size
  • font-family
  • font-weight
